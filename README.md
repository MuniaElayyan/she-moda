# She Moda — الموقع الكامل

## التشغيل
1. ثبّتي Node.js (النسخة 18 أو أحدث).
2. داخل المجلد:  npm install  ثم  npm start
3. افتحي http://localhost:3000

## دخول أصحاب المحل (3 حسابات فقط)
الدخول بالإيميل وكلمة المرور، ولا يوجد تسجيل حساب جديد نهائيًا.
لإنشاء الحسابات الثلاثة:  node set-owners.mjs email1 email2 email3
(يطبع كلمة مرور لكل إيميل ويحفظها مشفّرة في owners.json — لا يستطيع أحد غيرهم الدخول.)
من اللوحة: المنتجات، الأقسام، شريط العارضات، الطلبات، معلومات المحل (ساعات الدوام للشات بوت)، تغيير كلمة المرور.

## إيميل الطلبات (متغيرات بيئة)
ORDER_EMAIL=shemodagroup@gmail.com   (الافتراضي — هو الإيميل الوحيد الذي يصله تأكيد الطلب)
SMTP_HOST=smtp.gmail.com  SMTP_PORT=465
SMTP_USER=shemodagroup@gmail.com  SMTP_PASS=كلمة_مرور_التطبيق (App Password)
بدونها: يُحفظ الإيميل كملف HTML في data/outbox وتبقى الطلبات ظاهرة في لوحة التحكم.

## النشر
يلزم استضافة تدعم Node.js (Render, Railway…) مع قرص دائم، ووجّهي DATA_DIR إليه
حتى لا تضيع الصور المرفوعة والبيانات. أمر التشغيل: npm start

## الشات بوت
يعمل مباشرة بدون أي إعداد (يجيب من بيانات المحل). لجعله أذكى ومحادثة حرّة: ANTHROPIC_API_KEY=مفتاحك (اختياري، له تكلفة حسب الاستخدام).

## الموسيقى
لحن هادئ يُولَّد داخل المتصفح (بدون ملف صوتي)، يبدأ عند أول لمسة، وزر 🎵 أعلى الموقع لإيقافه.

## الرفع على GitHub
- الملف index.html موجود في الجذر (يحوّل تلقائيًا إلى public/index.html) وفي public/index.html.
- ⚠️ GitHub Pages استضافة ثابتة فقط: يعرض الموقع والأقسام والعربة والشات بوت، لكن **لا يعمل عليه** تسجيل دخول المالكين ولا إرسال الإيميل ولا حفظ الطلبات.
  وعندها يتحول تأكيد الطلب تلقائيًا إلى رسالة واتساب جاهزة. بياناته من public/data-static.json (نسخة ثابتة).
- للموقع الكامل: ارفعي المشروع على GitHub (يفضّل مستودع **Private**) ثم اربطيه بـ Render أو Railway (Web Service، أمر التشغيل: npm start)، وأضيفي متغيرات البيئة (SMTP_*، DATA_DIR على قرص دائم).
- ملف owners.json فيه إيميلات المالكين وكلمات مرورهم مشفّرة. بدل رفعه، يمكنك وضع محتواه في متغير بيئة اسمه OWNERS_JSON.
