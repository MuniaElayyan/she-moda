# She Moda — موقع المتجر

متجر أزياء نسائية في عتيل - طولكرم.
موقع ثابت مبني بـ **HTML + Tailwind CSS + JavaScript**، بدون أي ملف CSS تقليدي وبدون خطوة بناء.

---

## كيف أشغّل الموقع

افتحي `index.html` مباشرة بالمتصفح — يعمل فورًا.

للحصول على أفضل تجربة أثناء التطوير، شغّلي خادمًا محليًا (مثل إضافة **Live Server** في VS Code)
لأن بعض المتصفحات تقيّد قراءة الملفات عند الفتح المباشر.

> الموقع يحتاج اتصال إنترنت لتحميل Tailwind والخطوط من CDN.

---

## تعديلات شائعة

### إضافة منتج جديد
افتحي `js/data/products.js` وأضيفي عنصرًا:

```js
{
  name: 'اسم المنتج',
  category: 'abayat',        // المعرّف من categories.js
  image: 'عباية8.png',        // اسم ملف الصورة كما هو تمامًا
  price: 150,                // أو price: null إذا كان السعر عند الاستفسار
  sizes: 'من 38 إلى 42',      // اختياري
  colors: 3,                 // اختياري — يظهر «متوفر بـ 3 ألوان»
}
```
الكرت يُبنى تلقائيًا في صفحة المنتجات، ويُحدَّث عدّاد القسم وحده.

### تغيير رقم الهاتف أو العنوان
`js/data/site.js` — المكان الوحيد. يتحدّث الهيدر والفوتر وكل أزرار واتساب معًا.

### إضافة فيديو المتجر
ضعي ملف الفيديو بجانب `index.html`، ثم في `js/data/content.js` → `SheModa.videos`:

```js
src: 'store-outside.mp4',   // بدل null
```
يتحوّل المكان المحجوز تلقائيًا إلى مشغّل فيديو حقيقي. لا تستخدمي رابطًا من الإنترنت.

### رابط الخريطة
`js/data/site.js` → `links.maps` — مضبوط على موقع المتجر الحقيقي.
لو صار `null` تختفي أزرار «افتحي الموقع على الخريطة» تلقائيًا بدل أن تبقى معطّلة.

### تغيير ألوان الموقع
`js/theme.js` — لوحة `blush` هي الوردي الأساسي و`ink` هي الرمادي/الأسود.

## ⚠️ بيانات تجريبية يجب استبدالها

| ماذا | أين | ملاحظة |
|---|---|---|
| **أرقام «من نحن»**: 5 سنوات · 120 منتجًا · 900 زبونة | `js/data/content.js` ← `SheModa.stats` | أرقام مؤقتة للتصميم فقط. رقم «الأقسام» حقيقي ومحسوب تلقائيًا. |
| **سعر بلوزة هاينيك**: 45 شيكل | `js/data/products.js` | سعر تجريبي |
| **سعر البيجامة القطنية**: 90 شيكل | `js/data/products.js` | سعر تجريبي |

بعد وضع الأرقام الحقيقية، احذفي سطر التنبيه الظاهر أسفل قسم الأرقام في
`about.html` (الفقرة التي تبدأ بـ «أرقام تجريبية مؤقتة»).

ابحثي عن الرمز **⚠️** داخل ملفات `js/data/` للوصول إلى كل موضع بسرعة.

## قواعد المشروع

- ❌ لا يوجد ملف CSS تقليدي — التنسيق كله عبر أصناف Tailwind.
- ❌ ممنوع تغيير أسماء ملفات الصور أو حذفها (بعضها بالعربية وبمسافات وأقواس).
- ✅ الموقع بالكامل عربي RTL، واسم البراند **She Moda** بالإنجليزية فقط.
- ✅ كل قسم في الكود مسبوق بتعليق عربي يشرح وظيفته.

## ملفات حُذفت

بعد التأكد من عدم وجود أي اعتماد عليها في أي صفحة أو ملف:

| الملف | السبب |
|---|---|
| `style.css` | استُبدل بالكامل بـ Tailwind |
| `script.js` | استُبدل بوحدات مجلد `js/` |

## صور موجودة وغير معروضة حاليًا

**لم تُحذف ولن تُحذف** — باقية في المجلد كما هي:

| الملف | السبب |
|---|---|
| `2 (4).jpg` | نسخة مطابقة بالبايت لـ `3.jpg` |
| `ايميل.png` | لا يوجد بريد إلكتروني معلن للمتجر |
| صور الزبائن (`ام محمد.png` وأخواتها) | حُذفت الصور الشخصية من صفحة الآراء بطلب صاحب الموقع |

لعرض أي منها لاحقًا، أضيفيها في `js/data/content.js` أو `js/data/products.js`.
